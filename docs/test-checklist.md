# CP2 — Checklist kiểm thử LearningRadar

- [ ] Mở được prototype bằng `npm run dev` trong thư mục `prototype/`.
- [ ] Bôi đen một đoạn slide **hoặc** dán đoạn đó vào ô “Đoạn tài liệu cần hỏi”.
- [ ] Nhập câu hỏi và bấm **Gửi câu hỏi cho AI Tutor**.
- [ ] Kết quả mock hiển thị đủ: giải thích, citation và nhãn kiến thức.
- [ ] Bấm **Chưa hiểu** tạo ticket mới; mở Dashboard thấy ticket, lý do và đoạn text đã chọn.
- [ ] Làm quiz 5 câu, đạt từ 3/5: hiện kết quả pass và không tạo ticket.
- [ ] Làm quiz dưới 3/5: hiện kết quả fail; mở Dashboard thấy ticket có điểm quiz.
- [ ] Trên Dashboard, lọc được trạng thái ticket và TA đổi được trạng thái ticket.

Kết quả build: chạy `npm run build` không lỗi trước khi demo.
